##  데이터 구성요소
### 데이터가 왜 중요한가?
- 머신러닝은 규칙을 직접 코딩하지 않고, 데이터에서 규칙을 학습
- 데이터의 분포와 관계가 머신러닝의 학습 결과를 결정

### Feature (피처, 특성)
- 모델이 예측에 사용하는 입력정보
- 예측, 판단의 근거/단서

### Label(라벨, 목표값)
- 모델이 예측하려는 정답
- 학습의 목표값  


### ML 예시 
- 유튜브 추천 
  - 피쳐: 각 영상들의 정보, 사용자 정보(시청 이력, 구독 채널)
  - 라벨:
- 스팸메일 분류
  - 피쳐
  - 라벨


## 1D 피쳐 기반 학습
1D = 1차원  
Feature가 하나일 때 머신러닝이 학습하는 가장 단순한 형태   

피쳐(교육기간) 와 라벨(수입)을 함수로 따르는 f 가 있다.  
income = f(교육기간) +ε(측정 오차)  
여기서 f는 미지의 함수이다.  
income = label, 교육기간 = feature    
피쳐와 라벨의 관계를 잘 나타낸 함수 f는 무엇일까? : 측정오차가 작은 함수  

완벽한 True 함수 f*는 알 수 없다.  
우리가 보는 함수 f는 여러개의 후보 모델 중 가장 적합하다고 생각하는 모델인 것이다. 

## 모델과 가설 공간
### 학습
- 입력 -> 출력 관게를 찾는 과정
- 평균 관계를 하나의 함수로 표현함
- 하지만 관계를 표현할 수 있는 함수는 무수히 많음

### 가설 공간 
- 관계를 표현할 수 있는 모든 후보 함수들의 모음 
- 피쳐 공간과 라벨 공간 위에서 정의된 함수들의 집합

### 모델
가설공간에 속한 특정 함수 f 

## 2D 피쳐 기반 학습
2차원  
미지의 참 함수  (관측 불가), 엡실론도 관측불가
Income = f*(years of Education, seniority) + ε   

E(ε) = 0 이다.

## 왜 f()를 학습하는가  
### 예측
잘 학습된 f가 있으면, 새로운 입력 X= x 에서 반응/목표 Y를 예측할 수 있음

### 중요 특성 파악
피쳐들 X 중 어떤 특성이 Y를 설명하는데 중요하고 덜 중요한지 알 수 있음  

### 해석 가능성 
f의 복잡도에 따라 각 구성요소 Xi가 Y에 어떻게 영향을 미치는지 이해할 수 있음  


# 지도학습의 개념  

## 결정계수(R^2)

R^2 = 1 - (sum((yi-y^hat)^2)/ sum((yi - y bar)^2))    
    = 1 - MSE*N/sum((yi-ybar)^2)    
1에 가까울수록 설명력이 높다.      
즉 MSE의 값이 낮을수록 좋다.      
결정계수는 1이하이다.     
예측값이 평균값 보다 못하다면 음수가 나올 수 있다..!   

MSE: 직관적 해석 어려움   
R^2: 구체적 오차 크기를 모름

### 혼동행렬 

실제\예측   positive    negative  
    positive    TP          FN(error)    Sensitivity(Recall)
    negative    FP(error)   TN           Specificity

####  F1_score
F1 = 2* (precision*Sensitivity)/ (precision + sensitivity)
