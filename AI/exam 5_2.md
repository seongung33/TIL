## 스케일링의 법칙과 초거대 AI
- 파라미터 규모가 매우 큰 인공지능 모델 - 지식이 많다
- 대량의 데이터를 학습하여 여러 작업을 수행
- 데이터가 많고 모델이 클수록 성능이 좋아짐
- 분포 이동의 문제 존재
- 분포 이동의 리스크를 줄이기 위해 규모로 보험을 든다.  

### 분포 이동의 문제
그림 고양이를 통해 고양이를 학습함 -> 실제 고양이가 나온다면??     
AI가 학습할 때 경험한 세상과 실제로 쓰이는 순간의 세상이 달라질 때 발생하는 문제     

### 스케일링의 법칙 (스케일링 파라미터)
아래 세 가지 요소가 커질수록 AI의 성능이 지속적으로 향상된다.  
1. 모델의 크기 - 뇌의 용량  
2. 학습 데이터의 양 - 학습하게 되는 지식의 총량  
3. 컴퓨팅 자원 - 학습에 투입되는 GPU의 연산 능력  
규모를 키우는 것만으로 실전에서의 성능 저하를 줄일 수 있다.    
현재 AI 산업에서 사용하는 가장 리스크 적고 예측 가능한 투자 전략    

한계: 피지컬 AI  
피지컬 AI에서 분포 이동 문제의 심화 (폭발하는 경우의 수)    
환경 변수: 조도, 날씨, 재질 등    
로봇의 행동 변수: 시점, 거리, 모션 블러 등   

- 자본 및 자원의 집중: 막대한 자본과 GPU 연산이 필요하기 때문에 감당하기 힘듦
- 환경 및 프라이버시 문제: 대규모 연산으로 인한 지구 온난화, 데이터 수집과정에서의 개인정보 노출
- 물리적AI(피지컬 AI)의 복잡성: 자율주행, 로봇같은 AI의 경우 모든 상황을 커버하기에는 한계가 있다.  

이를 극복하기 위해 적응적 센싱을 사용한다.  
모델이 좋아하는 데이터를 센서 단계에서 조절해 주는 방식  
실제로 초거대 AI 모델에서도 센서 제어를 통해 입력을 최적화 하여 성능을 개선하였음  

## 적응적 센싱  
1. 분포 이동의 억제 
    - 모든 문제를 학습하거나 TTA를 이용하는 것이 아닌 환경에 맞춰 센서를 조절함으로써 AI 모델이 좋아하는 데이터를 제공  
    - 모델의 지식 확장 X -> 야생의 데이터를 모델의 지식 영역 안으로 밀어 넣는 방식  
2. 자연 지능(인간)과의 유사성 
    - 안경의 비유: 글씨가 흐릿할 때 수만 장의 흐릿한 글씨를 공부해서 극복하는 것이 AI
    - 하지만 안경을 써서 글씨를 선명하게 만드는 것이 적응적 센싱이다.  
    - 눈을 깜빡이거나 눈동자를 움직여 정보를 정제하듯, 센서 파라미터, 셔터 스피드 등을 조절하여 모델 친화적인 입력 제공 
3. 렌즈기법
    - 하나의 장면에 대해 파라미터를 바꿔가며 여러 장의 사진 촬영
    - AI 모델에 입력하여 Confidence Score 가 가장 높은 이미지를 골라 판단
    - 결과적으로 AI는 자신이 가장 잘 아는 형태의 데이터를 받아 처리합니다.
4. 적응적 센싱의 효용성
    - 초거대 AI와의 시너지: 추가적인 개선 가능
    - 효율성 극대화: 작은 모델과 데이터를 사용하더라도 센서 제어를 통해 더 높은 정확도 달성
    - AI의 취향 반영: 사람이 보기 좋은 사진이 AI가 잘 맞추는 사진이 아니다.  

## AI 가속기(NPU, TPU 등)의 구동 특성  
AI 가속기는 모델의 추론을 빠르게 처리하기 위해 설계된 전용 하드웨어  
특정 연산만 매우 빠르게 지원하도록 특화  
1. 정수 연산 중심의 설계
    - 정수 연산에 최적화: 정수 연산에서 훨씬 더 높은 속도와 효율성을 보여줌
    - TPU나 암(Arm)의 NPU 시리즈는 주로 8비트 또는 16비트 정수 모델을 실행하는 데 특화되어 있습니다.  
2. 범용성 대신 특화된 성능 (CPU와의 차이)
3. 연산 과정의 양자화 필요성 
    - 실수개입 차단: 실수가 연산 중간에 개입하면 AI 가속기에서 직접 구동이 불가능
    - 100% 정수 연산 구현: 비트 시프팅 같은 테크닉 사용을 위해 연산의 모든 단계를 정수로 변환  

일반적 양자화: r이라는 실수 값을 q라는 정수로 표현  
8비트 정수[0, 255]로 [rmin, rmax] 범위의 실수를 표현하려면 2가지 파라미터 필요
- 스케일링 파라미터 S (실수)
- 오프셋 파라미터 Z (정수)   
이때 스케일링 파라미터 사용으로 실수 연산이 필요(AI 가속기 구동 불가)

### 행렬곱 연산 양자화 사용
#### 실수 파트 묶기 
연산식에 흩어져 있는 여러 스케일링 파라미터(S1, S2, S3)를 하나의 실수값 M으로 묶어버리는 기법입니다  
. 실수를 한곳으로 몰아넣음으로써 해당 파트만 집중적으로 처리할 수 있게 만듭니다    
스케일링 파라미터를 정수화    
스케일링 파라미터는 실제로 (0, 1) 사이 이므로 스케일업 -> 양자화 및 연산 -> 스케일 다운   
#### 비트 시프팅(Bit shifting)
실수 M은 대개 (0, 1 )사이의 수라 정수화 하기 어려움.  
1. 2^n을 곱해 값을 임시로 스케일 업 합니다. 이때 비트를 왼쪽으로 미는(Scale-up) 비트 시프팅 사용  
2. 스케일 업 된 값을 정수로 반올림 하여 모든 행렬곱 연산을 정수만으로 수행
3. 연산이 끝난 후 비트를 다시 오른쪽으로 밀어 원래 스케일로 낮춥니다.(Scale-down)


## CNN 기반 TTA 기법
(Test-Time Adaptation, TTA)  
TTA 기법은 학습 단계가 아닌 테스트 단계에서 데이터의 분포이동에 적응하여 성능을 유지하는 기법  
1. 텐트(Tent)기법: 배치 정규화 계츠응ㄹ 테스트 데이터에 최적화  
 - TTA 세계에서 갖아 기본적이고 대표적인 기법. 주로 배치 정규화 계층을 테스트 데이터에 최적화하는 방식
 - 평균분산 업데이트: 평균과 분산을 테스트 데이터 기준으로 재계산
 - 어파인 파라미터 업데이트: 엔트로피를 손실함수로 설정. 역전파를 통해 값을 미세 조정
2. SAR: 더욱 안정적인 최적화
 - 선택적 적응: 노이즈나 이상치가 섞인 데이터가 불안정하게 만듦. 엔트로피가 특정 임계값보다 낮은 샘플만 골라 학습해 극복
 - 로스 평탄화: 로컬 미니마에 빠지는걸 막기 위해 로스 곡선을 평탄하게 만드는 작업  
SAR    
관찰: 노이즈나 이상치가 섞인 데이터가 불안정하게 만듦   
테스트 샘플 선택: 엔트로피가 낮은 테스트 샘플만 선택해 업데이트  
안정적 엔트로피 최소화: 엔트로피 손실이 너무 요동치지 않도록 평탄화  
결과: TENT보다 학습이 안정적이고, 테스트 환경에서도 성능 유지  

## PromptAlign 프롬프트 얼라인
학습데이터와 테스트 데이터를 직접 정렬시키자 -> 학습 데이터와 테스트 데이터 사이의 통계적 차이를 직접 줄인다.    
테스트 타임에 들어오는 데이터의 통계치를 학습 데이터의 통계치에 맞추도록 로스를 설계    
최종적으로 텍스트 프롬프트 + 이미지 프롬프트 모두 업데이트
