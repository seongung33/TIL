# 이미지 파운데이션 모델 

## AI 파운데이션 모델 
함수 또는 프로그램  
학습 = AI 모델에 데이터를 패턴화 하여 압축  
파운데이션: 대규모 데이터를 폭넓게 학습한 후 다양한 문제에 빠르게 적응할 수 있는 범용 대형 AI 모델  
특징
- 대규모: 트랜스포머 모델 + 대규모 언어 데이터 학습 
- 적응성: 높은 파인튜닝 성능
- 범용성: 다양한 작업, 한정되지 않는 출력 지원    

활용: 제로샷, few-shot, 파인튜닝  

## 시각 언어 모델  
CLIP  
AI가 언어와 시각을 통합해서 이해하는 방식을 보여준 패러다임 전환 제시  

## VLM (Vision Language Model)   
SigLIP  
softmax 대신 sigmoid 기반 손실함수   
일치하지 않는 음성 데이터에 제한된 영향만 받도록 손실함수 디자인을 고침  
멀티모달이다.  
멀티모달: 서로 다른 데이터 타입을 같이 다룸  
이미지와 텍스트를 동시에 이해하고 연결하는 것이다.   


LLaVA  
vision과 language모델을 결합한 모델(VLM), 텍스트와 이미지를 동시에 이해
