# 선형 회귀 
입력 변수와 출력 변수 사이의 관계를 직선 형태로 근사하여 예측하는 통계적 기법   
y = beta0 + beta1*X + epsilon    
## 최소제곱법 (least squares)
실제 관측값과 예측값의 차이를 제곱해 합한 값(RSS, 잔차제곱합)을 최소화하는 방법  
목표: 데이터를 가장 잘 설명하는 직선을 찾기 위해 계수 beta0, beta1을 추정  
### RSS 잔차 제곱합
잔차 정의: ei = yi - yihat  
RSS: e1^2+e2^2 + .... + en^2    
sumation(yi - beta0 - beta1*xi)^2    

## 다중선형회귀 
파라미터가 여러개임  

## 분류 
정해진 범주중 하나로 지정하는 것   
ex: 성별, 혈액형, 지역 등   

### 로지스틱 회귀 
시그모이드 함수를 활용해 0~1 범위 내 확률값으로 예측을 보장한다.  
시그모이드 함수: y = 1/(1+e^-z)  
z = beta0 + beta1*x    
로지스틱 함수는 선형함수 z를 내포하고 있따.  
### odds 오즈  
odds = 성공확률/(1-성공확률) = 성공확률/실패확률  
logit(로짓)변환 log odds  
우도(MLE): 현재 확률 함수가 데이터를 얼마나 잘 설명하는지  
로그로 변환 후 편미분하여 최대화하는 베타 값을 구한다.  

## 신경망  
shallow 네트워크, deep 네트워크의 구조  
### shallow 네트워크 
입력층 - 은닉층 1개 - 출력층 으로 구성된 1개의 은닉층만 가진 신경망 구조   
장점: 복잡한 비선형 패턴까지 학습 가능  
구조가 간단해 학습속도가 빠르고 구현이 쉬움  
과적합 위험이 낮음  
ex: 간단한 분류 및 회귀 문제   

ReLU 함수를 통해 비선형을 나타낸다.
ReLU: 음수는 0으로 양수는 해당 값 그대로  
y = f[x,Φ]  
= Φ0 + Φ1a[theta10 + tehta11x] + Φ2a[theta20 + theta21x]   
손실함수를 정의하고 손실을 최소화하도록 모수를 조정한다.  
모수: Φ, theta  
활성화함수를 통해 각 모수 별 함수를 만들고 이를 합치면 된다.  

### deep 네트워크
은닉 층이 여러개!  

## 손실함수   
모델이 예측을 얼마나 잘못했는지 측정하는 함수   
학습: 손실함수를 최소화하는 파라미터를 찾는 과정   
경사하강법: 손실함수를 줄이기 위해 기울기를 따라 내려가는 방법    

선형회귀의 손실함수: MSE가 될 수 있다.  
손실함수의 값이 줄어드는 방향으로 파라미터를 이동한다.  
미분을 이용해 최적화: 기울기 0인 지점 찾기  

### 경사하강법  GD
손실함수L[Φ]를 최소화하기 위해 파라미터 Φ를 반복적으로 갱신하는 알고리즘  
기울기 계산: 손실함수L[Φ]를 파라미터 Φ에 대해 편미분   
여러개의 지역 최소값이 갇힐 수 있다.  

확률적 경사하강법(SGD): 무작위 확률로 샘플된 일부 데이터만 사용하여 기울기 계산   
계산 비용 절감, 수렴 특성, 국소 최솟값  
## 역전파  
층 별로 파라미터 값들이 서로 영향을 끼침  
출력 오차를 기준으로 그래프를 거꾸로 따라가며 연쇄법칙으로 각 노드의 미분값을 계산하는 절차
