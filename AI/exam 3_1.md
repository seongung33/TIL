# CNN
입력 이미지를 필터와 연산하여 특징 맵을 뽑아내는 모듈    
1차원 구조로 변환하는 FCN과 달리 3차원(RGB) 구조를 그대로 보존하면서 연산  

## 합성곱 레이어  
Convolution(컨볼루션): 필터를 이미지 상에서 이동 시키면서 내적을 반복 수행, 내적으로 구한 모든 값을 출력 제공  
출력 해상도 = 입력 해상도 - 필터해상도 + 1  
해상도 유지를 위해 패딩 가능  
이후 활성화 함수(ReLU) 적용  이를 중첩 시킬 수 있다.  

## 풀링  : 효율적 연산 및 위치 변화의 강건성 확보  
CNN 레이어의 출력을 줄여 연산 효율성을 확보: 입력 크기가 줄면 CNN의 연산량이 크게 줄어듦  
예시: 2X2 풀링으로 입력의 해상도가 각각 1/2로 줄었을 경우.    
일반적으로  max pooling  최대값을 선택한다.


컨볼루션 > ReLU > pooling 순으로 진행 
위 과정을 여러번 반복 후 FC 진행  
컨볼루션 > ReLU 반복 후 pooling도 가능 

## 스트라이드 합성 곱 
일반 합성곱: 필터를 1칸씩 이동하면서 연산 수행   
스트라이드 합성곱: 필터를 스트라이드 값 만큼(S칸) 이동한 후 출력 연산  
효과: 풀링처럼 입력 해상도를 줄임 (연산 효율과 위치 강건성) 
특징 추출과 동시에 크기를 줄임  
풀링은 학습 상수가 없지만 스트라이드는 커널을 동시에 학습  
S 만큼 띄엄띄엄 칸을 보는 것이 컨불루션과 다르다.
S, stride= 1 이면 일반 합성 곱이다.
