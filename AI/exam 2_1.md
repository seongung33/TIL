## RNN  
RNN은 가변 길이의 입력을 받을 수 있고 이전 입력을 **기억**할 수 있기 때문에 ,  
순차적 데이터 처리에 적합한 아키텍처이다.   
따라서 RNN은 이전 시점의 정보를 담는 hidden state를 가지고 있다.   

특징:  
- 한 번에 하나의 요소를 처리하고 정보를 앞으로 전달한다.
- 펼쳐보면, 각 층이 하나의 시점을 나타내는 깊은 신경망처럼 보인다. 
- hidden state를 유지하면서 가변 길이 데이터를 처리할 수 있따.
- 출력은 과거 입력에 영향을 받는다는 점에서 feedforward 신경망과 다르다.   

기울기 소실 문제: 역전파 시 앞쪽 층의 기울기가 0에 가까워져서 장기 의존성 학습이 어렵다.  
why? 
1. 작은 값들이 곱해지며 값이 작아짐 
2. 과거 시점에서 온 오차는 갈수록 더 작은 기울기를 갖게 된다
3. 결국 파라미터들이 장기 의존성은 학습하지 못하고 단기 의존성만 포착하게 된다. 

## LSTM 
기울기 소실 문제를 해결하기 위해 제안된 RNN  
특징
- 시점 t에서 RNN은 길이가 n인 벡터 hidden state ht와 cell state Ct를 가진다. 
  - hidden state는 단기 정보를 저장한다.
  - cell state는 장기정보를 저장한다.
- cell state에서 정보를 읽고, 지우고, 기록할 수 있다.

3가지 게이트를 통해 어떤 정보를 지우고, 쓰고, 읽을지 결정한다. 
- Forget gate: 이전 cell state에서 무엇을 버리고 무엇을 유지할지 결정 
- Input gate: 새 정보 중 얼마나 cell state 에 쓸지 결정 
- Output gate: cell state 중 얼마나 hidden state로 내보낼지 결정

## transformer
self-attention: 문장 안에서 단어끼리 서로 중요도를 따져서 이해하는 방법  

### 어텐션  
Q: 내가 지금 찾고 싶은 것    
K: 각 단어가 가진 특징 (검색용)    
V: 실제 정보    
Q 랑 K 유사도 비교후 값이 높으면 V 많이 가져오기    

### 셀프 어텐션  
위 과정이 모두 한 번에 진행  
Q, K 간의 유사도를 계산해 softmax로 확률분포를 구한다.  
각 단어의 출력을 values의 가중합으로 계산한다.  

한계
- 순서 정보 부재
  - positional encoding - 각 단어 위치 i를 나타내는 위치벡터를 정의해 최종 입력으로 사용
- 비선형성 부족 
  - feed-forward network 를 추가해 깊고 비선형적인 표현으로 확장
- 미래 참조 문제 > 아직 생성되지 않아야할 미래 단어를 참조한다.  
  - masked self-attention: 미래 단어를 -무한대로 설정해 계산을 수행할때 반영 X

## 사전학습기반 언어모델
과거 단어들이 주어졌을 때, 다음 단어의 확률분포를 모델링하는 방법을 배움으로서, 사전학습을 수행할 수 있다.

### BERT 
인코더 모델. 2018년 구글에서 공개한 transformer 기반 모델로 masked LM 방법으로 사전학습을 수행했다.  
학습 방식: 입력 토큰의 15%를 무작위로 선택  
mask 토큰 치환80%, 랜덤 토큰 치환 10%, 그대로 두기 10%  
모델이 마스크된 단어에만 집중하지 않고 다양한 문맥 표현을 학습해 더 강건한 표현을 학습할 수 있도록 했다   

학습 방법 2 - NSP  (Next Sentence Prediction)  
입력을 두개의 연속된 텍스트로 받아, 두번째 문장이 첫번째 문장의 실제 다음 문장인지 여부를 예측하는 NSP를 수행했다.
