## 머신러닝 핵심 알고리즘

### 분류 - 이산형
- K - 최근접 이웃 (K-nearest neighbor)
  - 데이터가 들어왔을 때 가장 가까운 k개의 데이터를 한 그룹으로 판단
- 서포트 벡터 머신(Support Vector Machine, SVM) - 분류를 위한 기준선 정의
  - 결정 경계를 통해 분류
  - 결정 경계는 데이터가 분류된 클래스에서 가장 멀리 떨어져 있을 때 성능이 제일 좋다
  - 마진 - 결정 경계와 가까이 붙어있는 데이터. 이 데이터들이 결정 경계를 정의하는 역할을 한다고 볼 수 있다.
  - 최적의 결정 경계는 마진을 최대로 해야한다 - 이상치를 잘 다루어야 한다.
- 결정 트리 - 이상치가 많을 때 사용
  - 여러번의 분류를 하며 내려감
  - 불확실성을 계산 - 엔트로피, 지니계수
  - 엔트로피 - 엔트로피가 높을수록 불확실성이 높음
  - 지니계수 - 불순도를 측정하는 지표, 데이터의 통계적 분산 정도를 정량화해서 표현
- 로지스틱 회귀
- 비선형문제 분류하는법
  - 비선형 커널 도입 - 다항식 커널, 가우시안 RBF 커널

#### 판단
**혼동행렬**
| 실제 \ 예측 | Positive (예측) | Negative (예측) | 지표 |
|-------------|-----------------|-----------------|------|
| Positive (실제) | TP | FN | Recall = TP / (TP + FN) |
| Negative (실제) | FP | TN | Precision = TP / (TP + FP) |
| 전체 |  |  | Accuracy = (TP + TN) / (TP + TN + FP + FN) |

- Accuracy = (TP + TN) / (TP + TN + FP + FN)
- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1-score = 2 × (Precision × Recall) / (Precision + Recall)

## CNN, 합성곱 신경망 구조
1. 입력층 - 높이, 너비, 채널(RGB)로 (높이, 너비, 채널(컬러면 3))의 구조를 가지고 있음
2. 합성곱층 - 컨불루션, 이미지 특성을 감지하기 위해 커널과 필터를 사용 - 각 영역의 특성을 강조하여 값 출력
3. 풀링층 - 특성 맵의 차원을 다운 샘플링하여 연산량을 감소 시키고 주요한 특성 벡터만 추출하여 학습을 효과적으로 할 수 있게 함
4. 완전연결층 - 3차원 벡터에서 1차원 벡터로 펼친다. 
5. 출력층 - softmax 활성화 함수를 통해 입력받은 값을 0~1 사이로 출력하여 판단

## 지식 증류 
작은 모델을 만드는 효과적 방법
큰 모델(교사 모델) - 작은모델(학생 모델)   
정답은 하나지만, 큰 모델은 작은 모델에게 고양이 0.7, 호랑이 0.1 과 같이 확률적으로 알려줌  
softmax: temperature = 1 -> 일반적인 상태    
temperature > 1 -> 각각의 확률을 평준화 시킴    
temperature < 1 -> 분포가 날카로워짐(등장확률이 높은 것을 더 높게)   

여기서 교사 모델의 T가 너무 낮아 날카로워지면 학생 모델은 학습할 정보가 매우 적어짐   

지식 증류에는 보통 두 손실(Loss)을 같이 사용합니다.  
1. Hard Loss 
2. Distillation Loss

KL Divergence: 교사와 학생 모델의 분포가 얼마나 다른지 측정 - 값이 작을수록 학생 모델이 선생 모델을 잘 따른다.
