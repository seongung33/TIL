# 거대언어모델 
## 파운데이션 모델
대량의 데이터를 기반으로 사전 학습된 대규모 AI모델  
다양한 작업에 범욕적으로 활용할 수 있는 기초 역할  
3가지 구성요소
1. 빅데이터: 딥러닝 기반 ai 모델은 학습 데이터가 늘어날수록 성능 증가
2. 자가학습(selif-supervised Learning)알고리즘: 사람이 정답을 알려줄 필요 X
3. 어텐션(attention) 기반 트랜스포머(Transformer) 모델: 더 많은 데이터를 보다 잘 학습하고 이해할 수 있는 인공신경망 구조  

### 텍스트 파운데이션 모델 
더 많은 데이터, 큰 모델, 긴 학습 -> 더 좋은 성능    
창발성: 특정 규모를 넘어서면 모델에서 발현되는 성질    
단순한 요소들이 모였는데, 예상 못한 능력이 나타남   
폐쇄형 거대언어모델: 챗지피티, 클로드, 제미나이  
개방형: LLaMA, Qwen, Gemma

## 디코딩 알고리즘  
거대 언어 모델의 자동회귀 생성    
순차적 추론을 통한 토큰별 생성  
그럼 언제 멈추나요?: EOS 라는 종료 토큰 혹은 사전에 정의된 토큰 수 도달 시 종료  

### Greedy Decoding  
매 선택의 순간마다 가장 확률이 높은 토큰 선택  
장점: 사용하기 쉽다. 
단점: 직후만 고려하기 때문에 생성 응답이 최종적으로 최선이 아닐 수 있다.  

### Beam Search 
확률이 높은 K개의 후보를 동시에 고려  
매 시점마다 여러개의 후보를 선택 후 각 확률들의 누적 확률을 기준으로 상위 K개를 남긴다.  
장점: 최종적으로 좋은 응답 생성확률이 높다.
단점: 계산 비용이 많이 늘어난다.  

### Sampling  
거대 언어 모델이 제공한 확률을 기준으로 랜덤하게 생성  
장점: 다양한 응답을 생성할 수 있음
단점: 생성된 응답의 품질이 감소할 수 있음  

### Sampling with Temperature  
하이퍼 파라미터 T를 통해 확률분포를 임의로 조작    
T > 1: 확률분포를 편차가 낮게 생성 (낮은 확률을 높임)   
T < 1: 확률분포의 편차가 커지게 생성(높은 확률을 더 높임)  
T = 1: 거대 언어 모델이 만든 확률분포 그대로    

### TOP-K Sampling  
확률이 높은 K개의 토큰들 중에서만 랜덤하게 확률에 따라 샘플링   
장점: 품질이 낮은 응답을 생성할 가능성을 줄일 수 있음  
단점: 확률분포의 모양에 상관없이 고정된 K개의 후보군을 고려  
K = 4일떄 확률분포가 30 25 20 15 1 0.5 라면 좋은 상태이지만  
10 9.5 9.2 9 8.6 8 7 7 과 같이 비슷하다면 좋지 않은 상태이다.  

### TOP-P Sampling 
K를 고정하는 대신 누적화률 P에 집중하여 K를 자동으로 조절  
PCA의 차원축소 선택 비율과 비슷함  

## 거대 언어 모델 평가  
목표: 시스템으로 무엇을 달성하고자 하는지  
평가 방법: 어떤 방법으로 평가할 것인지  
평가 지표: 어떻게 성공 여부를 판단할 것인지  

- 정답이 정해진 경우  
  - 예측과 정답을 비교하여 일치도를 측정  

- 정답이 정해져 있지 않은 경우
  - 사람이 임의의 정답을 작성 및 이와 예측을 비교 
  - 정답과 무관하게 생성 텍스트 자체의 품질만을 측정 - perplexity(PPL)
  - 생성된 텍스트의 상대적 선호를 평가  

### 거대 언어 모델을 활용한 평가  
거대 언어 모델을 통해 생성 텍스트의 상대적 선호를 평가할 수 있음  
한계점
1. 위치편향: 특정 위치의 응답을 상대적으로 선호
2. 길이편향: 품질과 무관하게 길이가 긴 응답을 선호
3. 자기 선호 편향: 생성 모델과 평가 모델이 같은 경우, 이를 선호
