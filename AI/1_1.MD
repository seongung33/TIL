# AI & 기계학습기초  
## AI, ML, DL  
AI: 주어진 환경/데이터를 인지 학습 추론을 통해 목표달성을 하도록 예측 행동 선택 계획 하는 시스템    
ML: AI 범주 내에서 데이터로부터 학습하여 목적을 달성하는 접근 방법론    
ex) 생성형 AI, 언어 모델, 이미지 분류 모델, 추천 시스템     
DL: ML 범주 내에서 신경망 함수를 사용한 학습 방법론    
## 구성요소 (feature/Label)   
Feature: 모델이 예측에 사용하는 입력 정보, 예측 판단의 근거/예시    
Label: 모델이 예측하려는 정답, 학습의 목표값

# 지도학습
정답 라벨이 있는 훈련 데이터를 사용해 예측 모델을 학습하는 방법  
목표: 훈련 데이터로 학습한 모델이 새로운 데이터에서도 정확한 예측을 수행    
회귀와 분류가 있다.  
## 회귀 
MSE: 평균제곱오차    
R^2(결정계수): 음수가 나올 수 있다. 얼마나 잘 맞추는지 0~1 사이로 표기  
MSE = 1000만원: 평균적으로 실제 값과 천만원의 차이가 있다  
vs    
모델이 데이터 변동의 80%를 설명한다   
MSE: 구체적인 오차 크기, 실제 손실 비용 계산시  
R^2: 여러 모델 비교, 직관적 평가, 얼마나 좋은지 알고 싶을 때 

## 분류  
출력이 범주로 구분될 때  
분류 정확도: accuracy  맞춘 개수/ 전체 개수  
혼동 행렬을 봐야 한다.    

실제\예측   positive    negative    
    positive    TP          FN(error)    Sensitivity(Recall)  
    negative    FP(error)   TN           Specificity    
            precision   Negative predictive value   Accuracy     


F1 = 2* (precision*Sensitivity)/ (precision + sensitivity)   

## 목적  
새로운 데이터를 예측할 수 있다.  
평가법: 모델이 처음 보는 데이터로 평가 훈련 데이터 성능이 좋아도 새로운 데이터에 떨어지면 사용할 수 가 없다.  
(오버피팅)과적합: 훈련데이터의 잡음까지 외워버려서 훈련에서는 뛰어나지만 테스트 성능이 나쁘다    
언더피팅: 모델이 단순하거나 학습이 완료되지 않음
