# 반응형 웹과 UX/UI
## 반응형 웹 디자인 
디바이스 종류나 화면 크기에 상관없이, 어디서든 일관된 레이아웃 및 사용자 경험을 제공하는 디자인 기술  
### UX
제품이나 서비스를 사용하는 사람들이 느끼는 전체적인 경험과 만족도를 개선하고 최적화하기 위한 디자인과 개발 분야  
- 감각적 경험( 브랜드 인식): 러쉬만의 향기, 고급제품의 정교한 패키징
- 기능적 경험(오타 수정)
- 편의적 경험(흐름): 바쁜 아침 모바일 오더를 통해 빠른 픽업  

### UI
서비스와 사용자 간의 상호작용을 가능하게 하는 디자인 요소 개발 및 구현  
- UI 예시 
  - 물리적 UI : 리모컨
  - 복합적 UI : ATM 기기
  - 디지털 UI : 웹/앱 로그인 화면  

## Bootstrap Grid system 
웹 페이지 레이아웃을 조정하는 데 사용되는 **12개의 컬럼**으로 구성된 시스템  
왜 12개인가?: 약수가 많은 수로  화면 변경 시 이쁘게 떨어질 수 있다.  

## Grid system 구조와 문법 
Container(컨테이너): 컬럼을 담고 있는 공간  
column: 실제 컨텐츠를 포함하는 부분  
Gutter: 컬럼과 컬럼 사이의 여백  

기본적으로 row class를 만들고 아래에 추가로 col 컬럼을 생성하여 제작한다.  
Basic: col-2, col-10 등을 통해 12칸을 배분하면 된다.  
Nesting: 하나의 행-열을 만들고 다시 행 생성 후 열을 채워 넣으면 된다. 두번째 행 안에서 다시 12칸을 배분하면 된다.   
Offset: offset-4 를 하면 4칸을 띄우고 배치된다.  
Gutters: gx-0 을 통해 x축 조정, gy-5를 통해 y축 여백 조정, g-5로 모든 여백 조정  

행을 뜻하는 div의 class에 지정  후 열의 div도 만들어야 한다.  

## Grid system for responsive web 
부트스트랩에서는 12개의 column과 6개의 breakpoints를 사용하여 반응형 웹 디자인을 구현한다.  
### breakpoints
6개의 분기점  xs, sm, md, lg, xl, xxl 가 제공된다.  
xs < 576px, sm>= 576px, md>= 768px, lg>= 992px, xl >= 1200px, xxl >= 1400px  
사용법: col-sm-4, offset-sm-4
